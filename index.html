Netherrack is an experimental beta

Expect missing features, bugs and glitches, and back up any world you care about. Don’t expose a Netherrack server to the internet yet — see known limitations.

What works today

Netherrack is young, but it already covers the basics of running a Bedrock server, plus a small plugin API.

Join and play

Bedrock clients connect over NetherNet and can move around, fight other players, break and place blocks, middle-click to pick a block, craft in the 2×2 inventory or a right-clicked 3×3 table, eat food, and take damage from falls, lava and more — with health, hunger and real death. Gameplay is basic for now — see what’s still missing.

Generated terrain

The default world type generates rolling hills, valleys, lakes with sandy shores and scattered oak trees, all from the world’s seed. Terrain is still plains-only — no caves, ores, flowers or multiple biomes yet.

Flat world presets

Nine flat presets, from Classic Flat to The Void, for when you’d rather build on solid ground. See them all.

Worlds that persist

Worlds are saved in Bedrock’s own LevelDB format and autosaved every 30 seconds. Each one lives in worlds/<level-name>/.

Items in the world

Dropped items fall, slide to a stop and can be picked up again — and when a player dies, everything they carry drops where they fell.

Operators, permissions, bans and the whitelist

Five permission levels, /op and /deop, a permissions.json that remembers operators by Xbox Live ID, lasting player bans with /ban, an optional whitelist with /whitelist, and API permission nodes for plugins.

Plugins

Jars in plugins/ get lifecycle callbacks, commands, scheduled tasks, simple forms, damage/death/respawn, inventory/item, movement/teleport and metadata events, and offline-player lookup. Write a plugin.

Chat and commands

In-game chat with yellow join and leave messages. Commands work from both the console and the chat box, including /clear, /kick, /ban, /plugins and /reload. Command reference.

A friendly console

Customizable per-level formats and colors, a plain-text copy in logs/latest.log, logging reload with /reload, and a console in English or Brazilian Portuguese.

Try it in three steps

  1. Install Java 17 or newer. Check what you have with:

    java --version

  2. Download netherrack.jar from the Releases page and put it in its own folder.

  3. Run it from that folder:

    java -jar netherrack.jar

    Choose a language, accept the license, and wait for the Done! line. Then add a server in Minecraft: Bedrock Edition using your computer’s address and port 19132.

    On Linux or macOS, the NetherNet native library may need the JVM flags shown in the installation guide.

    Full details: Installation and Joining from Minecraft.

Not there yet

Netherrack is built from scratch and still growing. Things you won’t find yet:

  • Fully reliable runtime plugin reload — /reload is best-effort, so complex jars or plugin state still need a restart.
  • Mobs — the only entities in the world so far are items a player dropped.
  • Caves, ores, flowers and multiple biomes in generated terrain.
  • Furnace, stonecutter and smithing screens.
  • A finished login and play flow.

The Status page has the full checklist and the known limitations.

Built on open source

Netherrack uses open source CloudburstMC components for networking and the Bedrock protocol, plus libdatachannel-java, leveldb-mcpe-java and bundled vanilla data from several community projects.
