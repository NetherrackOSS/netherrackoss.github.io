Commands

What you can type in the console or in chat, and who is allowed to.

Running commands

  • In the console, type the command without a slash: gamemode creative Steve.
  • In the game, open chat and start with a slash: /gamemode creative. The game’s own command suggestions work too.

The same commands work in both places. Anything you type in chat without a slash is an ordinary chat message, shown to everyone. Netherrack logs every command a player runs, such as Steve issued command: /gamemode c.

If you type a command that doesn’t exist, you’re told so; if you lack the permission, you’re told that instead.

Plugins can declare their own commands in plugin.yml. They use the default command level and may require an API permission node; see plugin commands.

The Level column is the permission level needed — see below. Angle brackets <like this> are required; square brackets [like this] are optional.

/gamemode

The mode can be written in full or short:

ModeAccepted as
Survivalsurvival, s, 0
Creativecreative, c, 1
Adventureadventure, a, 2
Spectatorspectator, 6
Server defaultdefault, d

default uses the server’s default game mode from server.properties. From the console you must name a player, because the console isn’t one.

/op and /deop

The player must be online. /op saves them to permissions.json by Xbox Live ID, so they stay an operator across restarts and name changes. A player who isn’t signed into Xbox Live has no ID to save, so they can’t be made an operator. /deop removes them again; they go back to the default-player-permission-level.

Being an operator doesn’t unlock everything by itself — it depends on the permission level below.

/whitelist

Controls the allowlist in whitelist.json. /whitelist on and /whitelist off also update white-list in server.properties immediately. /whitelist list shows the saved entries, /whitelist reload re-reads the file after a hand edit, and /whitelist add|remove <player> works for offline names too. Adding an online player also saves their XUID and UUID so the entry survives a gamertag change. Level 3 is required, and operators bypass the whitelist.

/clear

Clears everything a player is carrying, including armor, offhand, the cursor and any open crafting grid. Players can clear themselves with /clear or /clear @s; the console must name a target. Level 2 is required.

/kick

Disconnects an online player. A reason can follow the name and is shown on their disconnect screen and in the console logout line, for example SchleroMC logged out due to: Disconnected. In-game leave messages are unchanged. Level 2 is required.

/plugins

Lists installed plugins alphabetically, e.g. Plugins (1): HelloPlugin. Names are lime green for players and in ANSI lime green on a color-capable console. The list includes disabled plugins, so check the startup log for load errors too. Everyone can use this command; see Plugins.

/reload

Re-reads the logs.debug, logging and labels sections of netherrack.yml without a restart. It doesn’t reload most other settings, and it doesn’t reload plugin jars — adding, removing or updating plugins still needs a restart. Level 4 is required.

/version

Include its output when you report a bug — it tells us exactly which build you’re running.

Example output of /version 
This server is running Netherrack
Server version: 0.4.0-beta (git commit: cee2419)
Java version: 21.0.4 (Eclipse Adoptium)
Operating system: Linux 6.1.0 (amd64)
Plugin API version: 0.4.0-SNAPSHOT

Permission levels

Every command needs a permission level. Everyone starts at 0, the console is at 4, and operators get the level in op-permission-level (2 by default).

LevelAdds these commands
0help, version, plugins — every player has this
2gamemode, give, clear, kill, kick, tp — what operators get by default
3op, deop, whitelist
4reload, stop — the console always has this
Letting operators run /op and /stop

With the default op-permission-level=2, operators can use the level-2 commands but not op, deop, whitelist, reload or stop. Raise it to 3 to let them manage operators and the whitelist, or 4 to let them reload logging and stop the server. Only give 4 to people you fully trust.
