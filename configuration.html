Configuration

Everything Netherrack reads is in plain text files next to the JAR. Stop the server before editing them — changes are read when it starts.

Files and folders

File or folderWhat it holds
server.propertiesThe main settings, below. Netherrack writes it with comments explaining each one.
netherrack.ymlSettings specific to Netherrack: debug logging, kick messages and the flat preset.
permissions.jsonThe operators, by Xbox Live ID.
nethernet-identity.pemThe server’s NetherNet identity, created on first start. Leave it alone — losing it changes how clients recognize the server.
worlds/<level-name>/A world: level.dat and a db folder (LevelDB), in the same layout Bedrock uses. Player data is saved with it.
logs/latest.logThe console, in plain text, for the current run. It’s overwritten each time the server starts — copy it first if you need it.

server.properties

The familiar Bedrock-style settings file, created on first run. Here’s every setting, with its default and whether Netherrack does anything with it yet.

KeyDefaultWhat it doesStatus
server-nameNetherrack ServerThe name shown in the server list. Any text without a semicolon.Works
gamemodesurvivalGame mode for new players: survival, creative or adventure.Works
difficultynormalMeant to set the difficulty (peaceful, easy, normal, hard). Right now the world always runs on Easy, whatever this says.Not applied yet
max-players20The most players that can be on the server at once.Works
online-modetrueMeant to require players to be signed into Xbox Live. It isn’t enforced yet: players who aren’t signed in can still join (a warning is logged).Not applied yet
server-port19132The UDP port to listen on, 1–65535.Works
server-ip0.0.0.0The address to listen on. 0.0.0.0 means every address on this machine.Works
view-distance32The largest view distance, in chunks, a player can use. 5 or more.Works
level-nameBedrock levelThe world to play on. It’s also the name of its folder inside worlds.Works
default-player-permission-levelmemberWhat new players start as: visitor, member or operator.Works
languageyour choiceThe language of the console: en-US or pt-BR. The wizard sets it on first run.Works
level-typeDEFAULTThe kind of world to create when the level doesn’t exist yet — a level that already exists keeps the type it was created with. default generates terrain: hills, valleys, lakes and trees, new every seed. flat makes a flat world, layered by the preset in level.preset-type. Commenting the line out is the same as default.Works
op-permission-level2Which commands operators can use, from 0 to 4. See permission levels.Works
Settings that aren’t applied yet

difficulty and online-mode are written to the file but nothing reads them yet. That matters for online-mode in particular: until it’s enforced, don’t rely on it to keep unauthenticated players out. See known limitations.

netherrack.yml

Settings that belong to Netherrack rather than to the Bedrock file format. Values can be plain or quoted, and # starts a comment.

netherrack.yml (without the comments Netherrack adds) 
logs:
  debug: false

messages:
  server-shutdown: "Server closed"
  server-whitelist: "You are not whitelisted on this server!"

level:
  preset-type: "Classic Flat"
SettingDefaultWhat it does
logs.debugfalseIf true, every network packet and other debugging detail goes into logs/latest.log (not the console). Handy when something goes wrong; the log grows quickly.
messages.server-shutdownServer closedWhat players still online are shown when the server closes.
messages.server-whitelistYou are not whitelisted on this server!Reserved for a whitelist, which doesn’t exist yet. Changing it has no effect for now.
level.preset-typeClassic FlatWhich flat preset a new flat world is built from. Only used when level-type is flat.

Flat world presets

Set level-type=flat in server.properties, then name a preset in level.preset-type in netherrack.yml. The names match the ones Minecraft shows in its world-creation screen.

PresetLayers, from the bottom up
Classic Flat1 bedrock, 2 dirt, 1 grass block
Tunneler's Dream1 bedrock, 230 stone, 5 dirt, 1 grass block
Water World1 bedrock, 64 deepslate, 5 stone, 5 dirt, 5 gravel, 90 water
Overworld1 bedrock, 59 stone, 3 dirt, 1 grass block
Snowy Kingdom1 bedrock, 59 stone, 3 dirt, 1 grass block, 1 snow layer
Bottomless Pit2 cobblestone, 3 dirt, 1 grass block
Desert1 bedrock, 3 stone, 52 sandstone, 8 sand
Redstone Ready1 bedrock, 3 stone, 116 sandstone
The VoidNo layers. Players start on a 33×33 stone platform at the bottom of the world.
Presets only apply to new worlds

A world keeps the type it was created with. Changing level-type or the preset has no effect on a world that already exists — see the guide to choosing a world type.

permissions.json

A list of operators, each identified by their Xbox Live ID (XUID) — a player’s name can change, their XUID can’t. You normally don’t edit this by hand: the /op and /deop commands change it for you. If the file doesn’t exist, Netherrack creates an empty one.

permissions.json (the XUID is just an example) 
[
  {
    "permission": "operator",
    "xuid": "2535400000000000"
  }
]

Players who aren’t signed into Xbox Live have no XUID, so they can’t be made operators.

Language

The language setting controls the console’s own messages: en-US (English) or pt-BR (Brazilian Portuguese). Players see the game itself in whatever language their client uses. To change it, edit the value and restart. Translations are ordinary .properties files in the project’s lang folder.
